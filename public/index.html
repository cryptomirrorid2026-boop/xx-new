Buku Panduan & Tutorial Lengkap

Pelajari cara menggunakan semua fitur bot dengan mudah tanpa bingung.

Langkah Memulai dari Awal (Quick Start)

Ikuti 4 langkah dasar ini agar bot langsung bisa mem-forward pesan.

1

Dapatkan Token Akun Discord (User Token)

Bot ini menggunakan akun Discord Anda sendiri untuk membaca channel (termasuk server VIP yang Anda masuki). Buka Discord di browser ➔ Tekan F12 ➔ Tab Network ➔ Cari request messages atau api ➔ Salin nilai header authorization.

⚠️ Jangan berikan token ini ke siapapun! Masukkan hanya di menu Bots & Tokens ➔ Discord Tokens.

2

Buat Bot Telegram di @BotFather

Di Telegram, cari @BotFather ➔ Kirim /newbot ➔ Beri nama bot ➔ Salin Bot Token yang diberikan (contoh: 8933930421:AAFna...). Masukkan token ini ke menu Bots & Tokens ➔ Telegram Bots #1.

Masukkan bot Anda ke dalam grup Telegram tujuan Anda dan jadikan sebagai Admin.

3

Ambil ID Channel Discord Sumber & Chat ID Telegram

Discord Channel ID: Aktifkan Developer Mode di Settings Discord ➔ Klik kanan channel yang ingin diforward ➔ Klik Copy Channel ID.

Telegram Chat ID: Masukkan bot @userinfobot ke grup Telegram Anda, atau forward pesan grup ke bot tersebut untuk mengetahui Chat ID (biasanya berawalan -100...).

4

Tambahkan Mapping Channel di Dashboard

Buka menu Channels (DC→TG) ➔ Klik Add Channel ➔ Masukkan Discord ID sumber, Telegram Chat ID tujuan, pilih Bot #1 ➔ Klik Save Mapping. Selesai! Pesan dari channel Discord tersebut akan otomatis ter-forward seketika.

Tutorial Lengkap Discord-to-Discord (DC ➔ DC Webhook)

Mirror dari server Discord orang lain ke server Discord Anda sendiri tanpa bot invite.

1

Cara Membuat Webhook di Server Discord Tujuan

1. Buka server Discord milik Anda sendiri.
2. Klik ikon gerigi (Settings) pada channel tujuan ➔ Pilih menu Integrations ➔ Klik Webhooks.
3. Klik New Webhook, beri nama sesuka Anda ➔ Klik Copy Webhook URL.

2

Whitelabeling & Branding Sendiri (Masking Profil)

Jika Anda tidak ingin member Anda mengetahui nama/avatar asli pengirim di server sumber:
- Isi kolom Custom Bot Name (misal: Nexus VIP Signals).
- Isi kolom Custom Avatar URL dengan link gambar logo Anda.
Semua pesan yang masuk ke server tujuan akan otomatis memakai nama dan logo brand Anda!

3

Memasang Auto-Ping / Mention Role di Server Tujuan

Agar member di server tujuan langsung mendapat notifikasi HP/Desktop saat sinyal baru masuk:
- Masukkan @everyone atau @here pada kolom Auto-Ping.
- Atau mention Role spesifik dengan format ID Role: <@&123456789012345678>.
(Cara dapat Role ID: Buka Server Settings ➔ Roles ➔ Klik titik tiga di role VIP ➔ Copy Role ID).

4

Forward ke Thread atau Forum Discord Spesifik

Jika channel tujuan Anda berupa Forum atau Thread, Anda cukup menyalin ID thread tersebut dan menempelkannya di kolom Discord Thread / Forum ID. Webhook akan otomatis mengirim pesan langsung ke dalam sub-thread tersebut.

Tutorial Telegram ke Discord (TG ➔ DC Mirror)

Mirror dari grup/channel Telegram sumber ke server Discord via Webhook.

1

Dapatkan API ID & API Hash

1. Buka situs resmi Telegram: my.telegram.org.
2. Login dengan nomor HP Telegram Anda ➔ Pilih menu API development tools.
3. Buat nama aplikasi bebas, lalu salin App api_id (angka) dan App api_hash (string huruf-angka).

2

Generate Session Userbot

Buka terminal di folder bot, lalu jalankan perintah:

node generate-tg-session.js

Ikuti petunjuk di terminal (masukkan nomor HP & kode OTP Telegram). Anda akan mendapatkan Session String panjang. Simpan di menu Bots & Tokens ➔ Telegram Userbot.

3

Hubungkan Mapping di Menu Channels (TG→DC)

Buka menu Channels (TG→DC) ➔ Klik Add TG→DC Mapping ➔ Masukkan Telegram Chat ID sumber dan Webhook URL Discord tujuan ➔ Simpan.

Panduan Saklar AI Watermark & Kecepatan Forward

Kendalikan kecepatan bot antara forward instan kilat atau pembersihan watermark gambar.

⚡

Mode Cepat (AI OFF) — Direkomendasikan untuk Kecepatan Maksimal!

Saat saklar AI dimatikan (AI SCAN: OFF), bot tidak melakukan scan OCR teks dan inpainting LaMa. Gambar langsung diforward secara instan dalam 1–3 detik saja.
Cara Mengaktifkan: Klik tombol pill di topbar pojok kanan atas hingga bertuliskan ⚡ Mode Cepat (AI OFF), atau kirim command telegram /ai off.

🤖

Mode AI Watermark Cleaner (AI ON)

Saat mode ini aktif (AI SCAN: ON), bot akan memindai teks pada gambar chart untuk mencari username/nomor HP/watermark terlarang, kemudian menghapusnya secara mulus menggunakan model AI LaMa inpainting.
Catatan: Mode ini membutuhkan komputasi CPU dan memakan waktu sekitar 10-30 detik per gambar.

✂️

Alternatif: Gunakan Crop Settings atau Smart Blur Manual

Jika ingin menghapus watermark tapi ingin tetap super cepat, gunakan menu Crop Settings (memotong border atas/bawah secara instan) atau Smart Blur dengan kotak template tetap. Proses ini berlangsung dalam hitungan milidetik tanpa AI scanner!

Panduan Anti-Spam GODMODE & Filter Kata

Lindungi server tujuan dari promosi liar, spammer, dan pesan bodong.

🛡️

Anti-Spam GODMODE 4 Layer

Bot dilengkapi 4 lapisan keamanan otomatis:
- Layer 1 (Blacklist Words): Hapus pesan jika mengandung kata bodong, scam, dll.
- Layer 2 (Rate Limiter): Cegah serangan flood/bom gambar spam.
- Layer 3 (Regex Pattern): Deteksi nomor WA, link invite discord liar, promo link.
- Layer 4 (Image Hash DB): Mengingat sidik jari visual gambar spam dan memblokir gambar serupa seketika.

✂️

Filter Kata Parsial (Menu Filter Kata)

Berbeda dengan Blacklist yang menghapus seluruh pesan, Filter Kata Parsial hanya menghapus kata terlarang saja, sementara sisa pesan tetap diteruskan dengan rapi ke server tujuan.

Tanya Jawab & Solusi Kendala Populer (FAQ)

Pertanyaan yang sering ditanyakan beserta solusinya.

Kenapa gambar forward terasa lama sampainya?
Penyebabnya adalah fitur AI Watermark Scanner yang memindai gambar menggunakan CPU. Untuk forward super instan (1-3 detik), klik tombol di topbar ⚡ Mode Cepat (AI OFF) atau kirim /ai off di Telegram.
Bagaimana cara agar mention Role di Discord Webhook benar-benar berbunyi?
Isi kolom Auto-Ping di channel mapping dengan @everyone, @here, atau format ID Role <@&ID_ROLE_ANDA>. Bot sudah dilengkapi parameter allowed_mentions sehingga Discord akan mengizinkan webhook memicu notifikasi suara/popup ke seluruh member role tersebut.
Apakah bot bisa forward ke Discord dan Telegram sekaligus bersamaan?
Bisa! Saat menambahkan Channel Mapping di menu Channels (DC→TG), cukup isi Telegram Chat ID DAN Discord Webhook URL secara bersamaan. Bot akan mengirimkan pesan ke kedua platform secara paralel tanpa saling memperlambat.
Bagaimana jika pesan di server sumber diedit atau dihapus?
Bot memiliki fitur Edit Sync dan Delete Sync. Jika pengirim asli di server sumber mengedit atau menghapus pesannya, bot akan otomatis mengedit dan menghapus pesan yang sama di Telegram maupun di Discord tujuan Anda secara real-time.
Bagaimana jika link Ngrok expired atau berganti?
Anda dapat menggunakan static domain gratis dari dashboard ngrok.com (misalnya doorway-suffice-washboard.ngrok-free.dev) dan memasukkannya ke variabel NGROK_DOMAIN di file .env. Dengan begitu link dashboard tidak akan pernah berubah.
